# Paper Results

This directory stores experiment outputs generated by the scripts in `research/papers/dw/scripts/`.

Suggested convention:

- keep only summary CSV and JSON metadata files under version control when they still correspond to manuscript-ready artifacts
- keep probe runs, test snapshots, and large exploratory outputs in a separate ignored scratch directory
- record the package commit hash, dirty flag, command, script hash, and input
	hashes in every metadata file

The committed files in this directory should match figures or tables that are
still wired into `research/papers/dw/Makefile`.

Run `make verify-results` from `research/papers/dw/` after regenerating results
to catch stale script or input hashes.

Metadata files with `frozen_snapshot: true` are legacy committed artifacts that
are intentionally skipped by the verifier until the corresponding experiment is
regenerated.
