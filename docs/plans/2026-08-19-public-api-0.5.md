# Public API 0.5.0 Implementation Plan

**Goal:** Deliver a minimal, Pythonic 0.5.0 public API by cutting unused/overlapping
knobs and removing the Bayesian evidence path. The two test functions keep only the
controls users actually need; `detect_harm` always returns `HarmResult` (no union).

**Breaking changes** (pre-1.0, acceptable): removes `statistic`, `alternative`,
`bayesian`, `threshold` parameters, `BayesianHarmResult`, `ShiftStatistic`,
`ShiftResult.statistic_name`, and the `_posterior` module.

**Architecture:** internal split (`_comparison.py`, `_statistics.py`) and all
non-Bayesian statistical behavior stay untouched. `TestResult` moves from
`_comparison.py` to `shift.py` (its public home); to avoid the resulting import
cycle, `run_permutation_test` returns a plain tuple and `_run_shift_test`
constructs `TestResult` in `shift.py`.

**Tech Stack:** Python 3.12, numpy, scipy, scikit-learn, pytest, ruff, uv.

## Final public surface

```
samesame.shift:
  Direction                  HIGHER_IS_WORSE | HIGHER_IS_BETTER
  detect_shift(source, target, *, n_resamples=9999, random_state=None, weights=None) -> ShiftResult
  detect_harm(source, target, *, direction, n_resamples=9999, random_state=None, weights=None) -> HarmResult
  ShiftResult                # statistic, pvalue, null_distribution
  HarmResult                 # + direction
  TestResult                 # base + significant(), __repr__

samesame.weights:
  from_domain_probabilities(*, source_prob, target_prob, mode="both", lambda_=0.5) -> ImportanceWeights
  ImportanceWeights          # .source, .target, .effective_sample_size() -> EffectiveSampleSize
  EffectiveSampleSize        # .source, .target
  WeightingMode              # Literal (kept)

samesame (root, flat):       detect_shift, detect_harm, Direction,
                             from_domain_probabilities, ImportanceWeights  <- NEW flat export
                             shift, weights
```

## Deleted

- `detect_harm` params: `bayesian`, `threshold` (union return type -> always `HarmResult`)
- `detect_shift` params: `statistic`, `alternative` (the latter had zero usages anywhere)
- `ShiftResult.statistic_name` field (becomes a constant -> pointless)
- `BayesianHarmResult` class
- `ShiftStatistic` type alias
- `_posterior.py` entire file (`compute_posterior_evidence`, `_bayesian_bootstrap`, `_bayes_factor`)
- `_resolve_posterior_threshold`, `_SHIFT_STATISTICS`, `_get_shift_statistic`, `_validate_shift_scores`
- `_PreparedHarmTest` dataclass (inlined; `_run_harm_test` returns `HarmResult` directly)
- `_run_shift_test` 4-tuple return -> returns `TestResult`
- `binary_scores`, `binary_shift_samples`, `bayes_factors` fixtures (dead after the cuts)
- 8 tests in `test_api.py` (bayesian/threshold/statistic-related)

## Moved

- `TestResult` (+ `significant()`, `__repr__`): `_comparison.py` -> `shift.py`.
  `run_permutation_test` returns `tuple[float, float, NDArray[np.float64]]` so
  `_comparison.py` no longer references `TestResult` (no import cycle).
