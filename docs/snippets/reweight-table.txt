| Mode | What it does | Use when |
|------|--------------|----------|
| `reweight="source"` | reweights source toward target; target unchanged | source has low-overlap observations outside target support |
| `reweight="target"` | reweights target toward source; source unchanged | target has low-overlap observations outside source support |
| `reweight="both"` (default) | reweights both toward mutual support | both groups have low-overlap regions |
